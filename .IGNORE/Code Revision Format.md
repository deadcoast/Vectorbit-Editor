# Code Enhancement Format

My code for my pixel art illustration software got scrambled transferring my files. I need you to analyze the JavaScript and css files I provide one by one, remove duplicates, but retain ALL features and functions, and provide the FULL corrected code file I submit back to me. 

---

## Code Revision Steps:

**GOLDEN RULE:** This is an ongoing project with many files and features. When you are generating code, *ALWAYS* retain functions and features. Never “streamline” or “remove” features. 

1. Understand Format: Confirm understanding of the requirements and the process.

2. Project Scope and Repository Structure: User submits project details, I confirm understanding of scope and structure. Always use the Repository Map for context of code improvements. This will help proper path, and context of other files functions.

3. Specify Folder: User specifies which folder we are working on.

4. Analysis and Suggestions: I analyze the files for duplicates, missing features, unimplemented features, and provide suggestions for enhancements, corrections, and QOL improvements.

5. Specify Suggestions: User selects which suggestions to implement.

6. Generate Corrected Code: I generate and provide the complete corrected code file(s) with the selected implementations.
